# Expenses MCP

## Introduction
This project is Spring boot MCP application that uses Sprinboot AI MCP starter to convert natural language to exact endpoints and share the requested response 

## Operations supported
- Add Expense
- Get Expense by ID

## Prerequisites
- Java 17 or later
- Claude Desktop
